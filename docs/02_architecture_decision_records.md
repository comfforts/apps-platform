# App Platform architecture decision records

This compatibility path is retained for existing documentation and external links. The canonical
router is the [architecture decision index](adr/README.md).

The index identifies the one current record for each decision, distinguishes decision status from
implementation and evidence status, and reserves future sequence without granting authority. The
[origin architecture decision record](adr/000-origin-architecture-decision-records.md) preserves
the former consolidated document as provenance; it cannot override an extracted decision.
